\# Hospital Data Warehouse and Business Intelligence Project



\## Overview



This project implements an end-to-end Data Warehouse and Business

Intelligence solution for hospital management data.



Two independent hospital management datasets are integrated using

SQL Server Integration Services (SSIS), SQL Server, SSAS, and Power BI.



\## Technologies



\- Microsoft SQL Server

\- SQL Server Management Studio (SSMS)

\- Visual Studio

\- SQL Server Integration Services (SSIS)

\- SQL Server Analysis Services (SSAS)

\- Microsoft Power BI
